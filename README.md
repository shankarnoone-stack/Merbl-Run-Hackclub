# Merbl Run

Merbl Run is a 3d printed marble run created in the software Onshape.
![Merbl Run CAD](Screenshot%202026-10-17%20185335.png)

## What is merbl?
It is a marble race you design from scratch. you build a base, and then tracks by sweeping profile along a path. You also create multiple parts for the race as well.


## Why?
This is for half life week 2, with cad.

## Printing
merbl is designed so that the tracks use the slicer generated supports (thin tree) as the supports for the track, therefore serving 2 purposes.
